           FRIDA — Guide d'installation
     Logiciel de gestion de successions notariales
════════════════════════════════════════════════════

PRÉREQUIS
─────────
• Windows 10 ou 11 (64 bits)
• 8 Go de RAM minimum (16 Go recommandé)
• 10 Go d'espace disque libre
• Connexion Internet (uniquement pour l'installation)
• Compte administrateur Windows (nécessaire pour installer WSL)


ÉTAPE 1 : Installer FRIDA
──────────────────────────
1. Décompressez le dossier reçu dans un dossier de votre choix
   (ex : C:\Frida ou sur le Bureau).

2. Vous devez avoir dans ce dossier :
   • Installer-Frida.bat
   • Installer-Frida.ps1
   • frida-micros.zip
   • sauvegarder.bat
   • restaurer.bat
   • desinstaller.bat
   • LISEZMOI.txt (ce fichier)

3. Double-cliquez sur « Installer-Frida.bat ».

4. Windows vous demandera d'autoriser les droits administrateur.
   → Cliquez sur « Oui ».

5. Le script vérifie et installe automatiquement :
   • WSL (sous-système Linux de Windows), si absent
   • Docker à l'intérieur de WSL
   • Les composants FRIDA (backend, frontend, lecture de QR codes)

6. Au premier lancement, l'opération prend 10 à 20 minutes
   (téléchargement + compilation).

7. Le navigateur s'ouvre automatiquement sur http://localhost


VOS IDENTIFIANTS DE CONNEXION
──────────────────────────────
À la fin de l'installation, une fenêtre affiche votre nom d'utilisateur
et votre mot de passe. Ils sont aussi écrits dans le fichier :

   C:\Users\<votre_nom>\Frida-Micros\IDENTIFIANTS.txt

⚠ Ce mot de passe est propre à VOTRE poste : il est généré au moment de
  l'installation. Conservez ce fichier en lieu sûr et ne le diffusez pas,
  il donne accès à tous vos dossiers de succession.


UTILISATION QUOTIDIENNE
───────────────────────
Deux raccourcis sont créés sur votre Bureau :

• FRIDA démarre TOUT SEUL à l'allumage du PC.
  Ouvrez simplement votre navigateur sur http://localhost
  (comptez une minute après l'ouverture de session).

• Si FRIDA ne répond pas :
  Double-cliquez sur « Demarrer-Frida » (raccourci du Bureau).
  Attendez ~30 secondes, le navigateur s'ouvre.

• Pour ARRÊTER FRIDA (et libérer la mémoire) :
  Double-cliquez sur « Arreter-Frida ».
  Vos données sont conservées. FRIDA repartira au prochain
  démarrage du PC.

• Pour SAUVEGARDER vos données :
  Double-cliquez sur « sauvegarder.bat », qui se trouve dans
  C:\Users\<votre_nom>\Frida-Micros\
  Un dossier daté est créé dans data\backups\.
  → Copiez ce dossier sur une clé USB ou un disque externe.

  ⚠ FAITES-LE RÉGULIÈREMENT. La sauvegarde est le seul moyen de
    récupérer vos fiches en cas de panne du PC.

• Pour RESTAURER une sauvegarde :
  Double-cliquez sur « restaurer.bat » (même dossier), puis indiquez
  le nom du dossier de sauvegarde à remettre en place.

⚠ « desinstaller.bat » SUPPRIME l'installation. Ne l'utilisez pas
  pour un arrêt quotidien : utilisez « Arreter-Frida ».


OÙ SONT MES DONNÉES ?
──────────────────────
Dans « C:\Users\<votre_nom>\Frida-Micros\data\ » :

  data\
  ├── uploads\    ← Vos documents scannés (PDF, images)
  └── backups\    ← Vos sauvegardes

La base de données (fiches, héritiers, calculs) est stockée à l'intérieur
de Docker et n'apparaît pas dans l'explorateur Windows. C'est normal :
PostgreSQL ne peut pas fonctionner depuis un dossier Windows.

→ C'est pourquoi « sauvegarder.bat » est important : il extrait la base
  vers data\backups\, où vous pouvez la copier sur une clé USB.

⚠ IMPORTANT : Aucune donnée ne quitte votre ordinateur.
  Les documents d'identité et extraits de naissance restent
  strictement sur cette machine.


PREMIÈRE INSTALLATION : ATTENTION AU REDÉMARRAGE
────────────────────────────────────────────────
Si votre PC n'a jamais utilisé WSL, l'installation peut demander
un redémarrage. Dans ce cas :

  1. Redémarrez Windows quand demandé.
  2. Après le redémarrage, une fenêtre noire Ubuntu s'ouvre :
     créez un nom d'utilisateur UNIX + un mot de passe.
  3. Fermez la fenêtre Ubuntu.
  4. RE-DOUBLE-CLIQUEZ sur « Installer-Frida.bat »
     pour reprendre l'installation.


EN CAS DE PROBLÈME
───────────────────
• « Docker installation failed » :
  → Vérifiez votre connexion Internet.
  → Relancez « Installer-Frida.bat ».

• « Port 80 déjà utilisé » :
  → Ouvrez « .env » dans C:\Users\<vous>\Frida-Micros\
  → Changez PORT_WEB=80 en PORT_WEB=8080
  → Relancez « Installer-Frida.bat » (le raccourci du Bureau est
    mis à jour avec le nouveau port)
  → Accédez à http://localhost:8080

• L'application est très lente :
  → Vérifiez que vous avez au moins 8 Go de RAM.
  → Fermez les applications gourmandes (Chrome, Photoshop, etc.).

• Autre problème :
